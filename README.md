# Родословная греческих богов

Интерактивное родословное древо греческих богов, титанов, нимф, чудовищ и героев: от Хаоса до Троянской войны и странствий Одиссея. Семнадцать ветвей древа, рассказ о каждом персонаже и поиск родства между любыми двумя.

Сайт: https://alex281172.github.io/zevs/

Основа древа — «Теогония» Гесиода. Дополнения — из Гомера, Гомеровых гимнов, Аполлодора, Овидия и других авторов. Где мифы расходятся, приведены все версии, а на древе другая версия показана пунктиром.

Все данные лежат в `data.js`: персонажи (`G`), браки и союзы (`U`) и ветви древа (`B`) с расположением карточек.
