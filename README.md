# Родословная греческих богов

Интерактивное родословное древо греческих богов, титанов, нимф, чудовищ и героев: от Хаоса до аргонавтов, Тесея, Троянской войны и странствий Одиссея. Всё древо на одном полотне, которое можно двигать во все стороны и приближать, двадцать одна ветвь по семьям, рассказ о каждом персонаже и поиск родства между любыми двумя.

Сайт: https://alex281172.github.io/zevs/

Основа древа — «Теогония» Гесиода. Дополнения — из Гомера, Гомеровых гимнов, Аполлодора, Овидия и других авторов. Где мифы расходятся, приведены все версии, а на древе другая версия показана пунктиром.

Общее древо раскладывается автоматически прямо в браузере, поэтому новые персонажи сами появляются на нём. Все данные лежат в `data.js`: персонажи (`G`), браки и союзы (`U`) и ветви древа (`B`) с расположением карточек.
